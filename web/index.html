Getting started

Run your first scenario in five steps. Real market data from Yahoo Finance / FRED is loaded by default.

  1. 1
    Market data loads automaticallyDefault tickers are pre-loaded on start. Edit them in the Market data settings below and Run to refresh.
  2. 2
    Build an allocationToggle assets and edit weights in the allocation bar, or apply a preset such as Classic 60/40.
  3. 3
    Review assumptionsDefaults use quadrant regimes, semi-Markov durations, and walk-forward validation.
  4. 4
    Run the simulationSet the horizon and path count if needed, then click Run Simulation.
  5. 5
    Read and exportUse Growth for outcomes, Diagnostics for model health, and Data for previews and downloads.
